## Выявленные проблемы

### 1. ❌ Subtitle (підзаголовок) не додається

**Приклад:** Д.1.1.1

**Ожидается:**
```
Дичківська О. О. Інноваційний менеджмент : конспект лекцій. Київ : ДІА, 2018. 82 с.
```

**Получено:**
```
Дичківська О. О. Інноваційний менеджмент. Київ : ДІА, 2018. 82 с.
```

**Проблема:** Поле `subtitle` игнорируется.

---

### 2. ❌ Edition (видання) форматується неправильно

**Приклад:** Д.1.1.5

**Ожидается:**
```
Релігієзнавство : навч. посіб. 2-ге вид., переробл. та допов. Київ : ЦУЛ, 2017. 193 с.
```

**Получено:**
```
Релігієзнавство : навч. посіб. Вид. 2-тє Київ : ЦУЛ, 2017. 193 с.
```

**Проблемы:**
- Неправильный формат: должно быть "2-ге вид." а не "Вид. 2-тє"
- Примечание `note` (переробл. та допов.) не добавляется
- Отсутствует точка после "допов."

---

### 3. ❌ Английские издания форматируются неправильно

**Приклад:** Д.1.1.6

**Ожидается:**
```
Parker J. Principles of scientific research. 7th ed. London : Editorial, 2017. 301 p.
```

**Получено:**
```
Parker J. Principles of scientific research. Вид. 7-тє London : Editorial, 2017. 301 с.
```

**Проблемы:**
- Для английских изданий должно быть "7th ed.", а не "Вид. 7-тє"
- Страницы должны быть "301 p.", а не "301 с."

---

### 4. ❌ Editor (редактор) не додається

**Приклад:** Д.1.1.7

**Ожидается:**
```
Міжнародний маркетинг : монографія / за заг. наук. ред. В. М. Марценюка. Київ, 2015. 374 с.
```

**Получено:**
```
Міжнародний маркетинг : монографія. Київ, 2015. 374 с.
```

**Проблема:** Информация о редакторе "/ за заг. наук. ред. В. М. Марценюка" отсутствует.

---

### 8. ❌ Статті: формат року

**Приклад:** Д.13.3.1

**Ожидается:**
```
Часопис Київського університету права. 2007. № 4. С. 88–92.
```

**Получено:**
```
Часопис Київського університету права. 2007, № 4. С. 88–92.
```

**Проблема:** Після року повинна бути ТОЧКА, а не КОМА.

---

### 9. ❌ Номер журналу: подвійні дефіси

**Приклад:** Д.13.3.2

**Ожидается:**
```
2017. № 5–6. С. 48–55.
```

**Получено:**
```
2017, № 5--6. С. 48–55.
```

**Проблемы:**
- Кома замість точки після року
- Подвійний дефіс "--" замість одинарного тире "–"

---

### 10. ❌ Англійські статті: інший формат

**Приклад:** Д.13.3.4

**Ожидается:**
```
2017. Vol. 18, No 2. P. 109–118.
```

**Получено:**
```
2017, Т. 18, № 2. С. 109–118.
```

**Проблемы:**
- Для англійських статей: "Vol." замість "Т.", "No" замість "№", "P." замість "С."
- Точка після року

---

### 11. ❌ Ініціали без пробілу


**Проблема:** В оригіналі немає пробілу між ініціалами, але це може бути опечатка в стандарті.

---

### 12. ❌ Конференції: формат дати та місця

**Проблема:** Інформація про дату та місце проведення відсутня або форматується неправильно.

1. **Subtitle** - додати підтримку підзаголовків

4. **Статті: рік** - точка замість коми після року

### Середній пріоритет:

### Низький пріоритет:
9. Зайві точки після знаків пунктуації

## Рекомендації

### 1. Визначення мови
Додати автоматичне визначення мови джерела для правильного форматування:
- Українська/Російська: "с.", "Т.", "№", "Вид."
- Англійська: "p.", "Vol.", "No", "ed."

### 2. Розширення підтримки полів BibTeX
Додати обробку:
- `subtitle` - підзаголовок
- `editor` з правильним форматуванням
- `note` для додаткової інформації про видання

### 3. Точна відповідність пунктуації
Реалізувати правильну розстановку точок, ком та двокрапок згідно ДСТУ.

### 4. Тестування
Створити регресійні тести для кожного пункту стандарту з точною перевіркою (assertEqual).
