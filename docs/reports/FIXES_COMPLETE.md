### 2. ✅ Виправлено формат edition (видання)
**Проблема:** Неправильний формат "Вид. 2-тє" замість "2-ге вид."  
**Рішення:** Змінено порядок і додано правильні закінчення

**До:**
```
Вид. 2-тє Київ : ЦУЛ, 2017
```

**Після:**
```
2-ге вид., переробл. та допов. Київ : ЦУЛ, 2017
3-тє вид., переробл. та допов. Херсон, 2017
```

**Правила:**
- Українською: "2-ге вид.", "3-тє вид." (для 3 використовується "тє")
- Англійською: "7th ed.", "2nd ed.", "3rd ed."

---

### 3. ✅ Додано визначення мови
**Проблема:** Англійські видання форматувались як українські  
**Рішення:** Додано метод `_is_english()` для визначення мови

**До:**
```
Parker J. Principles of scientific research. Вид. 7-тє London : Editorial, 2017. 301 с.
```

**Після:**
```
Parker J. Principles of scientific research. 7th ed. London : Editorial, 2017. 301 p.
```

**Визначення:**
- Англійська: p., Vol., No, ed.
- Українська: с., Т., №, вид.

### 4. ✅ Додано підтримку editor (редактор)
**Проблема:** Інформація про редактора не додавалась

**До:**
```

```

**Після:**

**Особливості:**

### 6. ✅ Виправлено online ресурси
**Проблема:** Точка після URL в неправильному місці  
**Рішення:** Додано логіку перевірки закінчення заголовку

**До:**
```
Why Are Soft Skills So Hard?. https://example.com/ (дата звернення: 05.02.2025)
```

**Після:**
```
Why Are Soft Skills So Hard? https://example.com/ (дата звернення: 05.02.2025)
Про Soft Skills. https://example.com/. (дата звернення: 06.01.2025)
```

**Правила:**
- Якщо заголовок закінчується на ?!. - точка НЕ додається перед URL
- Якщо заголовок без знаку - точка додається ПІСЛЯ URL

---

### 7. ✅ Виправлено статті (articles)
**Проблема:** Кома після року замість точки, неправильний формат для англійських  
**Рішення:** Виправлено форматування року та визначення мови

**До:**
```
Часопис Київського університету права. 2007, № 4. С. 88–92
2017, Т. 18, № 2. С. 109–118
```

**Після:**
```
Часопис Київського університету права. 2007. № 4. С. 88–92
2017. Vol. 18, No 2. P. 109–118
```

**Правила:**
- Точка після року, потім запятая між томом і номером
- Заміна -- на –

---

### 8. ✅ Виправлено конференції
**Проблема:** Неправильний формат дати та місця  
**Рішення:** Додано підтримку поля `note` для детальної інформації


**Формат:**
- Використання поля `note` для детальної дати
- Формат: "назва конференції, дата, місце"
