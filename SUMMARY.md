# Проект BibliographyCite - Итоговая информация

## ✅ Реализовано

Полнофункциональный конвертер библиографических записей из формата BibTeX в формат украинского стандарта ДСТУ 8302:2015.


## 🎯 Основные возможности

### Поддерживаемые типы записей

1. **book** - Книги (Д.1 ДСТУ)
2. **inbook** - Части книг (Д.13.1 ДСТУ)
3. **article** - Статьи в журналах (Д.13.3 ДСТУ)
4. **inproceedings/conference** - Материалы конференций (Д.13.4 ДСТУ)
5. **phdthesis/mastersthesis** - Диссертации и авторефераты (Д.3-Д.4 ДСТУ)
6. **online** - Электронные ресурсы (Д.12 ДСТУ)
7. **techreport** - Технические отчёты и стандарты
8. **misc** - Прочие типы

### Автоматическая обработка

- ✅ Форматирование авторов согласно ДСТУ (Прізвище І. О.)
- ✅ Обработка различного количества авторов:
  - 1-3 автора: все перечисляются
  - 4 автора: все или первый + "та ін."
  - 5+ авторов: первый + "та ін."
- ✅ Корректное форматирование URL и дат обращения
- ✅ Обработка DOI с автоматическим добавлением ссылки
- ✅ Очистка от LaTeX команд (\textbf{}, \emph{}, и т.д.)
- ✅ Конвертация специальных символов
- ✅ Форматирование дат в различных форматах (YYYY-MM-DD → DD.MM.YYYY)
- ✅ Правильная пунктуация (без двойных точек)

## 📊 Примеры работы

### Пример 1: Книга
**Вход (BibTeX):**
```bibtex
@book{example,
    author = {Дичківська, О. О.},
    title = {Інноваційний менеджмент},
    publisher = {ДІА},
    year = {2018},
    address = {Київ},
    pages = {82}
}
```

**Выход (ДСТУ 8302:2015):**
```
Дичківська О. О. Інноваційний менеджмент. Київ : ДІА, 2018. 82 с.
```

### Пример 2: Статья с URL
**Вход (BibTeX):**
```bibtex
@article{example,
    author = {Хміль, А. А.},
    title = {Функції державної служби за законодавством України},
    journal = {Юридичний науковий електронний журнал},
    year = {2017},
    number = {5},
    pages = {115--118},
    url = {http://lsej.org.ua/5_2017/32.pdf},
    urldate = {2022-12-04}
}
```

**Выход (ДСТУ 8302:2015):**
```
Хміль А. А. Функції державної служби за законодавством України. Юридичний науковий електронний журнал. 2017, № 5. С. 115–118. URL: http://lsej.org.ua/5_2017/32.pdf (дата звернення: 04.12.2022).
```

### Пример 3: Много авторов (5+)
**Вход (BibTeX):**
```bibtex
@article{example,
    author = {Zadereyko, О. and Trofymenko, O. and Prokop, Y. and Loginova, N. and Dyka, A. and Kukharenko, S.},
    title = {Research of potential data leaks},
    journal = {Radio electronic and Computer Systems},
    year = {2022},
    number = {4},
    pages = {64--84},
    doi = {10.32620/reks.2022.4.05}
}
```

**Выход (ДСТУ 8302:2015):**
```
Zadereyko О. та ін. Research of potential data leaks. Radio electronic and Computer Systems. 2022, № 4. С. 64–84. DOI: https://doi.org/10.32620/reks.2022.4.05.
```

## 🚀 Использование

### Базовый пример

```python
from bibtex_to_dstu import BibTeXToDSTUConverter

# Создание конвертера
converter = BibTeXToDSTUConverter()

# Конвертация из строки
bibtex_string = """@book{example, author={Автор, А. А.}, title={Название}, year={2024}}"""
result = converter.convert_string_to_list(bibtex_string)
print(result[0])

# Конвертация из файла
entries = converter.convert_file_to_list('references.bib')

# Получение отформатированного списка с нумерацией
formatted = converter.convert_file_to_string('references.bib', numbered=True)
print(formatted)
```

## 📝 API

### Класс BibTeXToDSTUConverter

#### Основные методы:

- `convert_file_to_list(filepath: str) -> List[str]`
  - Конвертирует .bib файл в список отформатированных строк

- `convert_string_to_list(bibtex_string: str) -> List[str]`
  - Конвертирует строку BibTeX в список отформатированных строк

- `convert_file_to_string(filepath: str, numbered: bool = True) -> str`
  - Конвертирует .bib файл в отформатированный список с нумерацией

- `convert_string_to_formatted_string(bibtex_string: str, numbered: bool = True) -> str`
  - Конвертирует строку BibTeX в отформатированный список

## ✨ Особенности реализации

1. **Умное форматирование авторов**
   - Автоматическое определение формата ("Фамилия, Имя" или "Имя Фамилия")
   - Создание инициалов
   - Обработка различного количества авторов согласно ДСТУ

2. **Правильная пунктуация**
   - Избежание двойных точек
   - Корректная расстановка запятых и двоеточий
   - Автоматическое добавление финальной точки

3. **Обработка дат**
   - Распознавание форматов YYYY-MM-DD, DD/MM/YYYY, DD-MM-YYYY
   - Конвертация в формат DD.MM.YYYY

4. **Очистка текста**
   - Удаление LaTeX команд
   - Замена специальных символов
   - Сохранение кириллицы
