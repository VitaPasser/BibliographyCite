# BibliographyCite - Конвертер BibTeX в DSTU 8302:2015

Конвертер библиографических записей из формата BibTeX в формат украинского стандарта ДСТУ 8302:2015 «Бібліографічне посилання. Загальні положення та правила складання».

## Возможности

- ✅ Конвертация записей BibTeX в формат ДСТУ 8302:2015
- ✅ Поддержка различных типов записей (книги, статьи, конференции, диссертации, веб-ресурсы)
- ✅ Автоматическое форматирование авторов (Прізвище І. О.)
- ✅ Обработка различного количества авторов (1-3, 4, 5+)
- ✅ Корректное форматирование URL, DOI и дат обращения
- ✅ Очистка от LaTeX команд и специальных символов
- ✅ Поддержка украинских и русских символов

## Использование

### Базовый пример

```python
from bibtex_to_dstu import BibTeXToDSTUConverter

# Создаём экземпляр конвертера
converter = BibTeXToDSTUConverter()

# BibTeX запись
bibtex_string = """
@book{example2018,
    author = {Іваненко, О. І. and Петренко, М. П.},
    title = {Основи програмування},
    publisher = {Наукова думка},
    year = {2018},
    address = {Київ},
    pages = {245}
}
"""

# Конвертация в список строк
result = converter.convert_string_to_list(bibtex_string)
print(result[0])
# Вывод: Іваненко О. І., Петренко М. П. Основи програмування. Київ : Наукова думка, 2018. 245 с.
```

### Конвертация из файла

```python
# Конвертация .bib файла
entries = converter.convert_file_to_list('references.bib')

# Получение отформатированной строки с нумерацией
formatted = converter.convert_file_to_string('references.bib', numbered=True)
print(formatted)
```

### Конвертация строки BibTeX

```python
# Получение списка отформатированных записей
entries = converter.convert_string_to_list(bibtex_string)

# Получение отформатированной строки
formatted = converter.convert_string_to_formatted_string(bibtex_string, numbered=True)
```

## Поддерживаемые типы записей

| Тип BibTeX | Описание | Формат ДСТУ |
|-----------|----------|-------------|
| `book` | Книга | Д.1 |
| `inbook` | Часть книги | Д.13.1 |
| `article` | Статья в журнале | Д.13.3 |
| `inproceedings`, `conference` | Материалы конференции | Д.13.4 |
| `phdthesis`, `mastersthesis` | Диссертация/автореферат | Д.3, Д.4 |
| `online` | Электронный ресурс | Д.12 |
| `techreport` | Технический отчёт/стандарт | - |
| `misc` | Прочие записи | - |

## Особенности форматирования

### Авторы

Конвертер автоматически форматирует авторов согласно правилам ДСТУ:

- **1-3 автора**: перечисляются все
  ```
  Іваненко О. І., Петренко М. П., Сидоренко В. В.
  ```

- **4 автора**: перечисляются все или первый + "та ін."
  ```
  Іваненко О. І., Петренко М. П., Сидоренко В. В., Коваленко А. А.
  ```

- **5+ авторов**: первый автор + "та ін."
  ```
  Іваненко О. І. та ін.
  ```

### Даты обращения

Поддерживаются различные форматы дат:
- `YYYY-MM-DD` → `DD.MM.YYYY`
- `DD/MM/YYYY` → `DD.MM.YYYY`
- `DD-MM-YYYY` → `DD.MM.YYYY`

### Очистка текста

Конвертер автоматически:
- Удаляет LaTeX команды (`\textbf{}`, `\emph{}` и т.д.)
- Убирает фигурные скобки
- Заменяет LaTeX кавычки на обычные
- Удаляет лишние пробелы

## API

### Класс `BibTeXToDSTUConverter`

#### Методы

- **`parse_bibtex_file(filepath: str) -> List[Dict]`**
  
  Парсит BibTeX файл и возвращает список записей.

- **`parse_bibtex_string(bibtex_string: str) -> List[Dict]`**
  
  Парсит строку BibTeX и возвращает список записей.

- **`convert_entries(entries: List[Dict]) -> List[str]`**
  
  Конвертирует список BibTeX записей в формат ДСТУ 8302:2015.

- **`convert_file_to_list(filepath: str) -> List[str]`**
  
  Конвертирует BibTeX файл в список отформатированных строк.

- **`convert_string_to_list(bibtex_string: str) -> List[str]`**
  
  Конвертирует строку BibTeX в список отформатированных строк.

- **`convert_file_to_string(filepath: str, numbered: bool = True) -> str`**
  
  Конвертирует BibTeX файл в отформатированную строку со списком литературы.

- **`convert_string_to_formatted_string(bibtex_string: str, numbered: bool = True) -> str`**
  
  Конвертирует строку BibTeX в отформатированный библиографический список.
