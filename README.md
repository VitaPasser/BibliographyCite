# BibliographyCite

[![Python 3.10+](https://img.shields.io/badge/python-3.10+-blue.svg)](https://www.python.org/downloads/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

Конвертер бібліографічних записів з формату BibTeX у формат українського стандарту **ДСТУ 8302:2015** «Бібліографічне посилання. Загальні положення та правила складання».

## ✨ Особливості

- ✅ **Повна відповідність ДСТУ 8302:2015** - 100% покриття стандарту
- ✅ **Підтримка всіх типів джерел**: книги, статті, конференції, дисертації, веб-ресурси, патенти, стандарти тощо
- ✅ **Автоматичне визначення мови** (українська/англійська)
- ✅ **Правильне форматування авторів** (Прізвище І. О.)
- ✅ **Родовий відмінок** для редакторів
- ✅ **Обробка різної кількості авторів** (1-3, 4, 5+)
- ✅ **Підтримка багатотомних видань**
- ✅ **Коректне форматування** URL, DOI, дат звернення
- ✅ **Очищення від LaTeX** команд та спеціальних символів
- ✅ **81 тест** з повною перевіркою відповідності

## 🚀 Швидкий старт

### Базовий приклад

```python
from bibliographycite import BibTeXToDSTUConverter

# Створюємо конвертер
converter = BibTeXToDSTUConverter()

# BibTeX запис
bibtex = """
@book{ivanov2020,
    author = {Іванов, О. І. and Петров, П. П.},
    title = {Основи програмування},
    subtitle = {навчальний посібник},
    publisher = {Наукова думка},
    year = {2020},
    address = {Київ},
    pages = {300}
}
"""

# Конвертуємо
result = converter.convert_string_to_list(bibtex)
print(result[0])
# Виведе: Іванов О. І., Петров П. П. Основи програмування : навчальний посібник. 
#         Київ : Наукова думка, 2020. 300 с.
```

### Конвертація з файлу

```python
from bibliographycite import BibTeXToDSTUConverter

converter = BibTeXToDSTUConverter()

# З файлу в список
references = converter.convert_file_to_list('references.bib')
for ref in references:
    print(ref)

# З файлу в пронумерований рядок
formatted = converter.convert_file_to_string('references.bib', numbered=True)
print(formatted)
```
